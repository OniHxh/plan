# Plan

App web (PWA) de suivi de patrimoine et d'objectifs d'épargne. Les données restent sur le téléphone.

- 1 point par mois : tu mets à jour tes soldes, l'app calcule le reste.
- Feu vert / orange / rouge selon ton rythme vers tes objectifs.
- « Je peux me permettre ? » : impact d'un achat sur tes objectifs.
- Charges fixes, abonnements, budget de dépenses courantes, revenus ponctuels.
- Sauvegarde : Réglages → Exporter / Importer (fichier JSON).

Installation sur iPhone : ouvrir l'adresse dans Safari → Partager → « Sur l'écran d'accueil ».
